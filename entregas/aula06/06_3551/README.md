# Respostas das Atividades – Programação 2 (2026)

Este repositório é destinado ao recebimento e centralização das soluções das atividades práticas da disciplina.

---

## Como Enviar sua Resposta

Para submeter seu exercício, siga o fluxo de contribuição via **Pull Request (PR)** do GitHub conforme as instruções abaixo:

### 1. Nomenclatura do Arquivo
O seu arquivo de resposta deve seguir rigorosamente a estrutura:
```text
<numero_atividade>_<matricula>_<nome_do_arquivo>
````

> **Exemplo:** Se a atividade for a **03**, sua matrícula for **123456** e o nome da entrega for `benchmark.py`, seu arquivo deve ser salvo como: `03_123456_benchmark.py`

### 2. Título do Pull Request

Ao abrir o Pull Request, utilize o seguinte padrão para o título:

Plaintext

```
<numero_atividade>_<matricula>
```

> **Exemplo de título do PR:** `03_123456`

## Checklist Antes do Envio

- [ ] O arquivo foi salvo com o padrão `<numero_atividade>_<matricula>_<nome_do_arquivo>`.
    
- [ ] O código foi testado localmente e executa sem erros via terminal.
    
- [ ] O título do Pull Request segue o formato `<numero_atividade>_<matricula>`.
